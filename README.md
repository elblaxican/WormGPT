# WormGPT

> An uncensored AI chat CLI built on OpenAI's ChatGPT API.

## Features

- **Jailbreak prompts** — Bypass standard content filters for unrestricted responses
- **Model selection** — Choose from GPT-4o, GPT-4, GPT-3.5-Turbo, and more
- **Conversation history** — Toggle persistent context across messages
- **Type writer output** — Watch responses render character by character
- **Configurable** — Save API keys and preferences to local config files


### Menu Options

| # | Option         | Description                              |
|---|----------------|------------------------------------------|
| 1 | WormGPT        | Start a chat session                     |
| 2 | Configure API  | Set or update your OpenAI API key        |
| 3 | Join Channel   | Open the support Telegram channel        |
| 4 | Change Model   | Switch between available GPT models      |
| 5 | Toggle History | Enable/disable conversation memory       |
| 6 | Exit           | Quit the application                     |

## Configuration

Two files are created on first run:

- **`key.txt`** — Stores your OpenAI API key (plain text)
- **`config.json`** — Stores model preference, temperature, and history settings

Edit `config.json` manually or use the in-app configuration menu.

## Requirements

- Python 3.8+
- OpenAI API key ([platform.openai.com](https://platform.openai.com/account/api-keys))

See `requirements.txt` for full dependency list.
